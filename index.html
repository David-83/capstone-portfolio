Flexographic Plate Workflow Management System

A capstone software project exploring how a web-based workflow application can improve the organization and visibility of flexographic printing plate requests.

PythonFlaskSQLiteHTML & CSSpytest
01 / Overview

From an operational challenge to a software solution

Flexographic plate production involves coordination among scheduling, plate making, plate mounting, and production. When request details are scattered across tools, teams may find it difficult to identify priorities and track progress.

This MSIT capstone develops a prototype web application for recording requests and presenting their status in a shared dashboard. It demonstrates requirements analysis, software implementation, data management, system integration, and testing.

Project scope: Academic prototype; not represented here as a production-deployed system.

02 / Featured project

Application overview

How it works

  1. A user enters a plate request with job number, job name, department, quantity, priority, and status.
  2. The Flask backend processes the form submission and stores a record in SQLite.
  3. The dashboard retrieves and displays saved requests for review.

The prototype provides a foundation for future workflow tracking, inventory management, and operational reporting.
